## ✨ Features

- **Discover Cinema:** Curated editorial catalog with high-fashion typography, TMDB live index, and mood-based subheadings.
- **Watch Next Showcase:** Atmospheric hero presentation with personalized metadata, backdrop scrims, and quick actions.
- **Personal Vault & Thoughts:** Log private screening dates, 10-point ratings, and written memory impressions.
- **TMDB API Gateway:** In-memory cached server-side gateway for trending movies, semantic searches, and recommendations.
- **Glassmorphism Floating Dock:** Zero-border circular navigation system with subtle ambient indicators.

---

## 🛠 Tech Stack

- **Framework:** Next.js 15 (App Router, React 19)
- **Styling:** Tailwind CSS, Lucide Icons, Sora & Cinzel typography
- **Database / Auth:** Supabase (PostgreSQL with RLS)
- **Deployment:** Render (`render.yaml` Blueprint)

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Rahullts/cineaste-movie-platform.git
cd cineaste-movie-platform

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
